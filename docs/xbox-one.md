# Xbox One

## Disable transcoding / set quality to original

1. Open the Plex app on Xbox One.
2. Select the media you want to play.
3. While the video is playing, press the `Menu` button on the controller.
4. Choose `Quality` or `Playback`.
5. Set quality to `Original` or the highest available setting.
6. If there is an option for `Direct Play` or `Direct Stream`, enable it.
7. Close the menu and continue playback.

## Notes

- If the media does not match the device capability, Plex may still transcode.
- This guide is for end users; Plex admins should confirm server settings if transcoding still occurs.
