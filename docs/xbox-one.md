# Xbox One

## Goal

Help Plex users choose the best playback path for Xbox One by picking original quality and enabling direct play when possible.

## Disable transcoding / set quality to original

1. Open the Plex app on Xbox One.
2. Select the show, movie, or clip.
3. Start playback.
4. Press the `Menu` button on the Xbox controller to open the playback overlay.
5. Select `Quality`, `Playback`, or `Video Quality` from the menu.
6. Choose `Original` or the highest available quality setting.
7. If `Direct Play` or `Direct Stream` is shown, turn it on.
8. Exit the menu and resume playback.

## When this helps

- The server can avoid re-encoding compatible files.
- The user sees the best available native quality.
- Playback is usually smoother when direct play is used.
