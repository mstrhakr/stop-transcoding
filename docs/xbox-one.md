## Xbox One

## Goal

Help Plex users choose the best playback path for Xbox One by picking original quality and enabling direct play when possible.

## Disable transcoding / set quality to original

1. Open the Plex app on Xbox One.
2. From the Plex home screen, open the app menu or select the gear icon for `Settings`.
3. Choose `Video` or `Player` settings.
4. Set `Local Quality` to `Original`.
5. Set `Remote Quality` to `Original` or the highest available quality.
6. Enable `Allow Direct Play` and `Allow Direct Stream` if those options are present.
7. Save or exit the settings screen.
8. Return to the home screen and play a video.

## When this helps

- Plex will use your default playback preferences for future videos.
- Compatible files can play without re-encoding.
- This avoids changing only one video at a time.

## Notes

- If the media is not supported by Xbox One, Plex may still transcode.
- If users cannot find Settings, look for a gear icon or a menu option from the app home screen.
