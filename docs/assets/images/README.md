# Image assets

Store Plex screenshot files under this folder.

Suggested filenames:

- `xbox-one-quality.png`
- `nvidia-shield-quality.png`
- `android-tv-quality.png`
- `roku-quality.png`
- `fire-tv-quality.png`
- `apple-tv-quality.png`

The docs reference images by path from the `docs/` folder, for example:

```md
![Xbox One Plex quality menu](assets/images/xbox-one-quality.png)
```
