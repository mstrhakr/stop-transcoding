# NVIDIA Shield

## Goal

Guide Plex users to choose original quality on NVIDIA Shield and avoid unnecessary server transcoding.

## Disable transcoding / set quality to original

1. Open Plex on NVIDIA Shield.
2. Select the title and begin playback.
3. During playback, press the `Up` or `Menu` button on the Shield remote.
4. Choose `Quality`, `Playback Settings`, or `Video Quality`.
5. Select `Original` or `Maximum` quality.
6. If `Direct Play` or `Direct Stream` appears, enable it.
7. Close the menu and continue playback.
