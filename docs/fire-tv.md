# Fire TV

## Goal

Help Fire TV users choose original quality to minimize server transcoding when the file is supported.

## Disable transcoding / set quality to original

1. Launch Plex on Amazon Fire TV.
2. Open the content you want to watch.
3. During playback, press the `Menu` button on the remote.
4. Select `Quality`, `Playback Settings`, or `Video Quality`.
5. Choose `Original` or the highest available quality.
6. Enable `Direct Play` or `Direct Stream` if available.
7. Resume playback.

## Notes

- Fire TV may transcode if the file contains unsupported audio or video codecs.
- If users still see transcoding, check the Plex server and codec compatibility.
