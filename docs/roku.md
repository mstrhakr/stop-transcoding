# Roku

## Disable transcoding / set quality to original

1. Open Plex on Roku.
2. Start the movie or show episode.
3. Press the `*` button on the Roku remote to open the playback options menu.
4. Select `Quality` or `Playback Settings`.
5. Set quality to `Original` or the highest quality available.
6. Turn on `Direct Play` or `Direct Stream` if shown.

## Notes

- Roku has more limited codec support than Shield or Apple TV.
- If Roku cannot play the file natively, Plex may transcode regardless of settings.
