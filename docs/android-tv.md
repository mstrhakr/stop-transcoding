# Android TV

## Disable transcoding / set quality to original

1. Open Plex on your Android TV device.
2. Select the title and start playback.
3. During playback, press the `Up` or `Menu` button on the remote.
4. Open `Quality` or `Video Quality`.
5. Choose `Original` or the highest available quality.
6. If available, enable `Direct Play` / `Direct Stream`.

## Notes

- Android TV devices vary by manufacturer, but the Plex playback menu is usually similar.
- If the media format is not supported, Plex will still transcode.
